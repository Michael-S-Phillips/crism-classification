# Pyroxene (pyx) Merge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Merge LCP+HCP into a single `pyx` deep-model class (7→6 class), as a single-variable change vs the champion, deferring ortho/clino to a post-hoc overlay (Spec B).

**Architecture:** The merge is a **dataset-load-time label collapse** in `_collapse_labels` (`pyx = max(lcp, hcp)`), mirroring the existing olivine-tier collapse — so the existing `mrral_pixels_7cls.parquet` is reused unchanged (no rebuild) and lcp/hcp are preserved for Spec B. A `--pyx` flag selects the 6-class pyx vocabulary. Training/metrics/inference/vectorizer are taught the new vocab; nothing else changes vs the champion recipe.

**Tech Stack:** Python, numpy, pandas, torch, rasterio; conda env `crism` (`conda run -n crism python`); HPC slurm.

## Global Constraints

- Reuse `data/mrral_pixels_7cls.parquet` as-is (it has `lcp`,`hcp` columns) — **no build/parquet rebuild**.
- pyx vocabulary (order matters): `['olivine','pyx','plagioclase','bland','alteration','junk']`.
- Head width 6 is **ambiguous** (alteration-6cls = `[...,'other','alteration']` vs pyx-6cls); pyx inference/vectorizer must be told the vocab explicitly (a `--pyx` flag), never inferred from head width alone.
- `val_mAP_core` = mAP **excluding `junk`** whenever `junk` is in the label set (pyx core = olivine/pyx/plagioclase/bland/alteration).
- Single-variable vs champion `ft_7cls_v3b_lrscale001`: same v3-bland encoder, raw reflectance, honest splits, MTRDR synth-plag, 3-arm lrscale, stop `val_mAP_core`.
